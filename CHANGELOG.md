# Changelog

All notable changes to the "xcaffold" extension will be documented in this file.

## [0.1.0] - 2026-05-04
- Initial release of xcaffold for VS Code.
- Integrated JSON Schema for `*.xcf` manifest validation.
- Added validate-on-save diagnostics using `xcaffold validate`.
- Added interactive D3.js Resource Graph.
- Added xcaffold Resource Explorer sidebar.
- Added Command Palette integration for `apply`, `status`, `list`, and `import`.
